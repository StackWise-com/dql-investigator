# Dynatrace Query Language

*Latest Dynatrace · Reference · Updated on Jan 28, 2026*

The docs call DQL "a powerful tool to explore your data." Teams can analyze telemetry held in Grail to surface trends, irregularities, and statistical models.

Because "DQL offers maximum flexibility because it is built for processing arbitrary event data," it does not rely on fixed schemas, setting it apart from conventional relational stores.

The article recommends starting with the usage guide, then branching into these resources:

- **Language reference** – comprehensive syntax details

- **DQL examples for security data** – security telemetry scenarios
- **DQL examples for business events** – examining and displaying business event information
- **DQL examples for Davis problems and events** – constructing health dashboards from intelligence reports
